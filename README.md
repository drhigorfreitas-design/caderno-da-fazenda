# Caderno da Fazenda

App de controle de produção e custos de uma fazenda de gado de corte (cria, recria e engorda), baseado no Método Inttegra.

- `index.html`: o app (página única). Hoje roda como artifact do Claude, com os dados salvos na nuvem do Claude.
- `supabase-schema.sql`: tabelas do projeto Supabase `fazenda` (região São Paulo), com segurança por usuário (RLS).

Este repositório é privado.
